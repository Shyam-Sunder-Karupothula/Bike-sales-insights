# Bike Sales Insights Report - Power BI

This Power BI report analyzes bike resale trends across India using a dataset containing features like brand, model, price, mileage, insurance status, registration year, and more.

 ## Key Insights Uncovered:
- Top performing bike brands driving resale value.
- Fuel type trends: Petrol vs Hybrid and their impact on resale.
- Depreciation patterns by year of manufacture.
- How different ownership types affect resale price.
- State-wise performance and regional demand trends.
- Mileage efficiency across engine capacity bands.
- Registration year trends reflecting resale activity over time.
